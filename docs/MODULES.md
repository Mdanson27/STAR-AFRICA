# Modules

| Module | Current capability |
| --- | --- |
| Executive dashboard | Populated KPIs, cash-flow visualisation, action queue, projects, margins, activity |
| Bids & tenders | Opportunity/workspace structure, checklist, expenses, sources, conversion service |
| Projects | Configurable stages, portfolio, milestones/tasks, budget and profitability structure |
| Procurement | Request → approval → RFQ → quote → PO → receipt → bill topology |
| Inventory | Items, warehouses, movements, project allocation, batch/expiry structure |
| Customers & suppliers | Master data, contacts, balances and relationship links |
| Invoices & payments | Exact totals, VAT/retention, partial/multi-invoice allocation, posting drafts |
| Accounting | Accounts, periods, journals/lines, balancing validation, reversals |
| Banking | Accounts, statement transactions, matching and reconciliation history |
| Payroll & HR | Employees, payroll runs/entries/components and configurable rules |
| Documents & OCR | R2/document metadata model, links, OCR jobs, confirmation/provider boundary |
| Reports & calendar | Complete report catalogue surface and operational events |
| Administration | Users, roles, permissions, approvals, tax, audit, backups and migration |

All major module routes implement populated, filtered, empty, loading, and recoverable error states. Creation dialogs explicitly disclose development persistence until D1 migrations are applied.
