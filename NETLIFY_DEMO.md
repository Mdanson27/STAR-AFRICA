# Star Africa OS — Netlify Demo

This repository is configured for the Star Africa OS functional demo on Netlify.

## Runtime

- Standard Next.js App Router
- Netlify Functions for server-side execution
- Netlify Blobs for private uploaded documents
- Demo authentication enabled only for the demo deployment
